# Contributing

This project is **source-available**. External contributions (issues, pull requests, discussions) are not accepted.

The source is published under Apache 2.0 so that integrators and partners can read, audit, and understand the CI/CD pipelines that build and publish the VION libraries they consume — not as an invitation to collaborate.

For questions or problem reports, contact `info@vion-iot.com`.

For security vulnerabilities, see [SECURITY.md](SECURITY.md).
